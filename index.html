Featured Projects

GIAT UMPO - Sistem KKN Kampus

Sistem informasi manajemen Kuliah Kerja Nyata (KKN) untuk Universitas Muhammadiyah Ponorogo. Mencakup dashboard LPPM, manajemen periode, pendaftaran mahasiswa, pengelolaan kelompok dosen, dan monitoring kegiatan KKN secara terintegrasi.

Web App Backend REST API Database

STD UMPO - Sinkronisasi Data Kampus

Sistem jembatan data yang mengintegrasikan Datasim (Data Sistem Informasi Mahasiswa) kampus dengan Feeder PDDIKTI secara real-time. Memfasilitasi sinkronisasi biodata mahasiswa, aktivitas akademik, dan pelaporan data perguruan tinggi ke pangkalan data nasional secara efisien dan akurat.

Web App Backend REST API Data Integration

SUARA UMPO - Platform Survey Kampus

Platform survei digital berbasis metode SERVQUAL yang dirancang khusus untuk lingkungan perguruan tinggi. Mendukung pembuatan dan pengelolaan lebih dari 30 jenis survei, mulai dari evaluasi kepuasan layanan akademik, kinerja dosen, hingga umpan balik stakeholder — semuanya dalam satu dashboard terintegrasi dengan analitik real-time.

Web App SERVQUAL Analytics Backend

SIMFT - Sistem Informasi Akreditasi

Sistem informasi yang dirancang khusus untuk Fakultas Teknik guna memfasilitasi proses akreditasi. Mengelola data dosen, mahasiswa, penelitian, dan pengabdian masyarakat secara terpusat untuk mendukung penyusunan borang dan pemenuhan standar penilaian akreditasi.

Web App Data Management Accreditation Reporting
